# CorpUman - Joc educațional despre corpul uman

Acesta este un prototip de joc web care ajută adolescenții să învețe despre corpul uman printr-un exercițiu interactiv.

Fișiere:
- `index.html` – nivelul principal al jocului
- `styles.css` – stiluri moderne pentru o experiență adolescentină
- `script.js` – logică interactivă și quiz

Deschide `index.html` într-un browser pentru a porni jocul.
